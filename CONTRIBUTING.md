# 🤝 Contributing to Next-Visualizer

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).



## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/N-Zik-Group/Next-Visualizer.git

## ✅ Verify your changes

Use the Gradle wrapper to run `./gradlew build`. For visual changes, include a short capture showing the effect on a representative audio session.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
